# Kit «secondo cervello»

Un kit per creare un secondo cervello: una cartella di file markdown che un'AI legge prima di ogni lavoro e aggiorna
dopo, con le regole scritte una volta sola, dei controlli automatici e, se vuoi, la sincronizzazione su GitHub e una
routine serale che lo tiene in ordine. Funziona con Claude, ChatGPT e Codex, Gemini e Antigravity, Copilot, Cursor e
altre AI, perché tutto sta in file aperti.

- **Per installarlo con un'AI**: apri un agente con il terminale e scrivigli «Leggi e segui INSTALLA.md di questo
  repository», con l'indirizzo di questa pagina. Le istruzioni per l'AI sono in [INSTALLA.md](INSTALLA.md).
- **Per leggere prima**: [LEGGIMI.md](LEGGIMI.md) in una pagina, poi la guida completa in [GUIDA.md](GUIDA.md).
- **I prompt da incollare**: [PROMPT-DI-AVVIO.md](PROMPT-DI-AVVIO.md). **Le schede per ogni AI**: [piattaforme/](piattaforme/).
- **Il cervello vuoto da copiare**: [modello/](modello/).

Il kit è pubblico, il tuo cervello no: quando lo metti su GitHub, il suo repository è sempre privato.
